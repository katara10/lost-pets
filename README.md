# Lost Pets — поиск потерянных животных

Веб-приложение для размещения объявлений о потерянных и найденных животных.

## Назначение

Пользователи публикуют объявления с местом и датой пропажи или находки, отслеживают
статус поиска, печатают листовки для расклейки и делятся объявлениями.

## Пользовательские сценарии

1. Просмотр ленты объявлений с фильтрами.
2. Просмотр карточки объявления.
3. Создание и редактирование объявления.
4. Печать листовки для расклейки.
5. Шаринг объявления в соцсети.
6. Личный кабинет со своими объявлениями.

## Экраны

| URL | Экран |
|-----|-------|
| `/` | Лента объявлений |
| `/ads/:id` | Карточка объявления |
| `/ads/new` | Создание объявления |
| `/ads/:id/print` | Листовка для печати |
| `/profile` | Личный кабинет |
| `/login` | Вход |

| `*` | 404 |

## Backend

Серверная часть проекта реализована на Python с использованием фреймворка FastAPI, ORM SQLAlchemy и СУБД PostgreSQL.

### 1. Подготовка базы данных
Для работы бэкенда необходима установленная СУБД PostgreSQL. 
Создайте пустую базу данных (например, через pgAdmin или консоль psql).

Выполните следующий SQL-запрос:
CREATE DATABASE lost_pets_db;

### 2. Настройка переменных окружения
В папке backend/ создайте файл .env (он добавлен в .gitignore и не попадет в репозиторий). 
В нем необходимо указать строку подключения к вашей базе данных. 

Пример содержимого файла .env:
DATABASE_URL=postgresql://postgres:ваш_пароль@localhost:5432/lost_pets_db

В репозитории также присутствует файл .env.example с шаблоном настроек без секретов.

### 3. Установка зависимостей
Перейдите в папку backend, создайте виртуальное окружение и установите необходимые библиотеки.

Выполните команды в терминале:
cd backend
python -m venv venv

Для активации окружения используйте одну из команд (в зависимости от вашей ОС):
- Windows (Git Bash): source venv/Scripts/activate
- Windows (CMD): venv\Scripts\activate
- macOS/Linux: source venv/bin/activate

После активации установите зависимости:
pip install -r requirements.txt

### 4. Запуск сервера
Убедитесь, что вы находитесь в папке backend и ваше виртуальное окружение активировано. Запустите сервер разработки:

uvicorn app.main:app --reload

Сервер запустится по адресу: http://127.0.0.1:8000.


## Модель данных

Основная сущность проекта — **Объявление (Ad)**. На текущем этапе (ЛР №2) реализована одна таблица в базе данных.

**Таблица ads (SQLAlchemy):**
* id (Integer, Primary Key) — уникальный идентификатор объявления.
* type (Enum) — тип объявления: lost (потеряно) или found (найдено).
* species (String) — вид животного (кошка, собака и т.д.).
* name (String) — кличка животного.
* description (Text) — подробное описание (приметы, особенности).
* location (String) — адрес или район, где потеряно/найдено животное.
* date (DateTime) — дата пропажи или находки.
* status (Enum) — текущий статус: active (активно), found (найдено), closed (закрыто).
* contact_phone (String) — контактный телефон.
* contact_name (String, Optional) — имя контактного лица.
* created_at (DateTime) — дата и время создания записи в базе данных.
